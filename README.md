# ArcRec

- **アーチェリー記録会管理システム**。
- Ianseo（<https://www.ianseo.net/Releases.php>）互換で動作、学校・チーム内の記録会を想定している。
- ScorekeeperNG（ISK-NG）の Lite モードで得点を入力できる。
- WA形式の予選（1セッション、1〜2距離）に対応する。（マッチ戦、3距離以上、部門ごとに異なる的面には対応しない。）
- Outdoor は1距離36射、Indoor は1距離30射である。
- スコアカードPDF・結果PDF・CSVを出力できる。

## 動作環境

- PHP 7.4以上（PHP 8.3で動作確認済み。セキュリティ更新が提供されているPHPを推奨）
- PHP拡張: `pdo_sqlite`、`mbstring`、`zlib`
- ScorekeeperNGを使う場合、ScorekeeperNGが動作する端末からサーバーへ接続できるネットワーク
- Webサーバーから `data/`（または設定したデータ保存先）へ書き込めること

## ダウンロードと共通の設置手順

- [リリース一覧](https://github.com/e-donkun/arcrec/releases)から `ArcRec-バージョン.zip` をダウンロードし、ZIPを展開する。
- 展開したファイル一式（`index.php` を含む）を、Webサーバーの公開ディレクトリまたはその配下のフォルダーに配置する。
- 必要に応じて [`config.sample.php`](config.sample.php) を `config.php` にコピーし、`data_dir` と全体管理者パスワードを設定する。`config.php` は秘密情報を含むため、Git管理外で保管する。
- 既定では記録会データは `data/` に保存される。公開フォルダ外に保存する場合は、`data_dir` を実際のパスに変更する。全体管理者パスワードを空欄にすると、管理画面で初回設定できる。

## 記録会設定と使い方

- 管理画面で全体管理者としてログインし、「新しい記録会を作成」から記録会を作成する。
- 記録会ごとに個別パスワードがあり、全体管理者パスワードでも各記録会を開ける。
- 記録会設定でOutdoor / Indoor、距離数、的の種類を選択する。
- 部門にはコード・名称・並び順を設定する。
- 参加者は画面から登録するか、CSVから一括で追加する。
- ScorekeeperNGは管理画面の「端末設定」にあるQRコードを読み取る。QRを使わない場合は、表示されたサーバーURLと記録会コードを入力する。
- ScorekeeperNGで点数入力する。
- 「点数管理」で入力状況を確認し、「全員を確定」するとScorekeeperNGからの入力がブロックされる。
- 管理画面の「結果」では順位を確認し、結果PDF / CSVを出力できる。結果を公開にした記録会は公開ページに表示される。
- 不要な記録会は設定画面から削除できる。サンプル記録会を削除した場合も、自動では復活しない。

## セキュリティとバックアップ

- 公開されたサーバで運用する場合は、`data/` をWebから直接アクセスできないようにする。
- バックアップではデータ保存先にある記録会データ（`competitions/`）と管理者設定ファイルを保存する。

## 制限事項

- マッチ戦、3距離以上、部門ごとに異なる的面には対応しない。正式な競技会では Ianseoを用いること。
- ScorekeeperNGの実機接続を含め、本番前にリハーサルで一連の操作を確認すること。

# ArcRec

- **アーチェリー記録会管理システム**です。
- Ianseo（<https://www.ianseo.net>）互換の学校内やチーム内の記録会を想定したシステム。
- Ianseoと同じようにScorekeeperNG（ISK-NG）の Lite モードで得点入力できる。
- WA 形式の予選（1セッション、1〜2距離）に対応する。
- Outdoor は1距離36射、Indoor は1距離30射。
- スコアカードPDF・結果PDF・CSV で出力できる。

## 動作環境

- PHP 7.4 以上（PHP 8.3 で動作確認済み）
- PHP 拡張: `pdo_sqlite`、`mbstring`、`zlib`
- ScorekeeperNG を使う場合、タブレットからサーバーへ接続できるネットワーク

## 設置と初期設定

- Web サーバーの公開フォルダに ArcRec を配置する。

```sh
git clone https://github.com/e-donkun/arcrec
```

- 配置した URL を開くと、参加者向けの記録会一覧が表示される。
- 管理画面は URL の末尾に `admin/` を付けて開く。
- 初回は管理者メニューの「管理者パスワードを設定」から共通の管理者パスワードを設定すること。
- サンプル記録会（屋外・屋内）が含まれており、どちらのパスワードも `sample` 。
- 記録会データは `data/competitions/` に保存される。
- `data/` が Web から直接見えないように設定すること。
  - Apache は同梱の設定でアクセスを拒否する。
  - nginx の場合は `data/` へのアクセスを拒否する設定が必要。
- データ保存先の変更や管理者パスワードの事前設定には、任意の `config.local.php` を配置できる。

```php
<?php
return [
    'data_dir' => '/var/lib/arcrec',
    'admin_password' => '管理者パスワード',
];
```

## 使い方

### 記録会の作成と設定

- 管理者としてログインし、「新しい記録会を作成」から記録会名、競技形式、記録会用パスワードを設定する。
- 記録会ごとに個別パスワードがあり、共通の管理者パスワードでも各記録会を開ける。
- 記録会設定では、Outdoor / Indoor、距離数、的の種類を選択。
- 部門にはコード・名称・並び順を設定する。
- 名簿に未登録の部門が含まれる CSV を取り込む場合は、先に部門を登録すること。
- 同点時の第1・第2優先順位は詳細設定から変更できる。

### 参加者と的番号

- 参加者は画面から登録するか、UTF-8 / Shift_JIS の CSV から一括で取り込む。
- 過去の記録会に登録した参加者も追加できる。
- 参加者ごとに的番号と位置（A〜F）を割り当てる。
- 割り当て表で移動するか、一覧から番号（例: `1A`）を入力する。
- 得点が入力された参加者の割り当ては変更できない。
- スコアカード PDF は参加者一覧または入力状況の画面から出力できる。

### ScorekeeperNG での入力

- 管理画面の「端末設定」で「QRコード」を ScorekeeperNG で読み取る。
- QR を使わない場合は、同じ画面に表示されるサーバー URL と記録会コードをアプリに入力する。

### 得点の確認と結果公開

- 「点数管理」では入力状況を確認し、必要に応じて素点を編集できる。
- 「全員を確定」すると、ScorekeeperNG からの追加・変更入力が停止する。
- 管理画面の「結果」では順位を確認し、結果 PDF / CSV を出力できる。
- 記録会管理ホームで結果を公開にした記録会だけが表示される。
- 公開ページから結果 PDF をダウンロードできる。


## セキュリティとバックアップ

- 記録会ごとの個別パスワードと全体管理者パスワードは異なる。
- `data/` を Web から直接アクセスできないように設定する。
- バックアップでは `data/` 内の記録会データ（`data/competitions/`）を保存する。


## 制限事項

- 対応するのは WA形式の予選（1〜2距離、1セッション）である。マッチ戦、3距離以上、部門ごとに異なる的面には対応しない。
- ScorekeeperNG の実機接続を含め、本番前にリハーサルで一連の操作を確認すること。

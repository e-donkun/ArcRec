# ArcRec

**アーチェリー記録会管理システム**です。ScorekeeperNG（ISK-NG）の Lite モードで得点を入力できます。

WA 形式の予選（1セッション、1〜2距離）に対応します。Outdoor は1距離36射、Indoor は1距離30射です。結果はスコアカード PDF・結果 PDF・CSV で出力できます。

## 動作環境

- PHP 7.4 以上（PHP 8.3 で動作確認済み）
- PHP 拡張: `pdo_sqlite`、`mbstring`、`zlib`
- ScorekeeperNG を使う場合、タブレットからサーバーへ接続できるネットワーク

## 設置と初期設定

Web サーバーの公開フォルダに ArcRec を配置します。

```sh
git clone https://github.com/e-donkun/arcrec
```

配置した URL を開くと参加者向けの記録会一覧が表示されます。管理画面は URL の末尾に `admin/` を付けて開きます。

初回は管理者メニューで「管理者パスワードを設定」から共通の管理者パスワードを設定してください。サンプル記録会（屋外・屋内）が含まれており、どちらもパスワードは `sample` です。

記録会データは `data/competitions/` に保存されます。`data/` が Web から直接見えないようにしてください（Apache は同梱の設定で拒否します。nginx の場合は `/arcrec/data/` へのアクセスを拒否する設定が必要です）。

データ保存先を変更する場合や、管理者パスワードを事前設定する場合は、任意の `config.local.php` を配置できます。

```php
<?php
return [
    'data_dir' => '/var/lib/arcrec',
    'admin_password' => '管理者パスワード',
];
```

## 使い方

### 記録会の作成と設定

管理者としてログインし、「新しい記録会を作成」から記録会名、競技形式、記録会用パスワードを設定します。記録会ごとに個別パスワードがあり、共通の管理者パスワードでも各記録会を開けます。

記録会設定では、Outdoor / Indoor と距離数、的の種類を選べます。部門はコード・名称・並び順を設定してください。名簿に未登録の部門が含まれる CSV を取り込む場合は、先に部門を登録します。同点時の第1・第2優先順位も詳細設定から変更できます。

### 参加者と的番号

参加者は画面から登録するか、UTF-8 / Shift_JIS の CSV からまとめて取り込みます。過去の記録会に登録した参加者も追加できます。

参加者ごとに的番号と位置（A〜F）を割り当てます。割り当て表で移動するか、一覧から番号（例: `1A`）を入力してください。得点が入力された参加者の割り当ては変更できません。スコアカード PDF は参加者一覧または入力状況の画面から出力できます。

### ScorekeeperNG での入力

管理画面の「端末設定」で「接続設定の QR」を ScorekeeperNG で読み取り、モードを **Lite** にします。QR を使わない場合は、同じ画面に表示されるサーバー URL と記録会コードをアプリに入力してください。QR は管理画面をタブレットから到達できる URL（`localhost` ではなく、サーバーの LAN アドレスなど）で開いて表示します。

選手と的番号を設定した後、「的の QR」を読み取ると、その的の選手が表示されます。入力した得点はサーバーに保存されます。2距離の場合は前半・後半を選べます。

### 得点の確認と結果公開

「点数管理」では入力状況を確認し、必要に応じて素点を編集できます。「全員を確定」すると ScorekeeperNG からの追加・変更入力が止まります。

管理画面の「結果」では順位を確認し、結果 PDF / CSV を出力できます。参加者向けの結果ページはトップページにあります。記録会管理ホームで結果を公開にした記録会だけが表示され、公開ページからは結果 PDF をダウンロードできます。結果 CSV は管理画面からのみ出力できます。

## セキュリティとバックアップ

- 記録会のパスワードと共通の管理者パスワードを設定し、他人と共有しないでください。インターネットに公開する場合は HTTPS を使用してください。
- `data/` を Web から直接アクセスできないようにしてください。
- バックアップは `data/` 内の記録会データ（`data/competitions/`）を保存してください。SQLite の `-wal` / `-shm` ファイルがある場合は、それらも一緒に保存します。
- 記録会結果を公開すると、誰でも公開ページと結果 PDF を閲覧できます。公開が不要になったら非公開に戻してください。


## 制限事項

- 対応するのは WA 形式の予選（1〜2距離、1セッション）です。マッチ戦、3距離以上、部門ごとに異なる的面には対応していません。
- ScorekeeperNG の実機接続を含め、本番前にリハーサルで一連の操作を確認してください。
